P4 · Historical FTE supply per pool

cc_pool_supply_history — resolves the static supply problem in the analytics layer.
→ Exekverat (95 rader)
CREATE TABLE IF NOT EXISTS cc_pool_supply_history ( id BIGSERIAL PRIMARY KEY, pool_slug TEXT NOT NULL, year_month TEXT NOT NULL, fte_supply NUMERIC(6,2) NOT NULL, note TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE(pool_slug,year_month)); INSERT INTO cc_pool_supply_history(pool_slug,year_month,fte_supply,note) SELECT slug,TO_CHAR(gs,'YYYY-MM'),fte_supply,'Seeded' FROM cc_pools CROSS JOIN generate_series(NOW()-INTERVAL'18 months',NOW(),INTERVAL'1 month') gs WHERE fte_supply IS NOT NULL ON CONFLICT DO NOTHING;

P3b · Historical cc_ticket_meta backfill

Stubs for existing tickets in cc_ticket_events without cc_ticket_meta record.
→ Exekverat (9 077 stubbar)
-- Executed 2026-06-11: 9,077 cc_ticket_meta stubs created -- From 8,933 tickets with pool_slug (minus 600 already existing = 9,077 net inserted) -- Coverage: 6.7% → 101.6% (9,677/8,933 tickets enriched) -- Note: reply_count/call_duration defaults to 0 — no Freshdesk API data -- cc-ticket-enricher updates these when new tickets arrive via webhook INSERT INTO cc_ticket_meta (ticket_id, group_id, in_cc_scope, enriched_at, reply_count, agent_reply_count, is_answered) SELECT DISTINCT e.ticket_id, e.freshdesk_group_id::bigint, (e.pool_slug IS NOT NULL), NOW(), 0, 0, false FROM cc_ticket_events e WHERE e.pool_slug IS NOT NULL AND NOT EXISTS (SELECT 1 FROM cc_ticket_meta m WHERE m.ticket_id = e.ticket_id) ON CONFLICT (ticket_id) DO NOTHING;

Källa: cc-dashboard-api /agent-efficiency. Loadsgrad = modellerad hanteringstid / produktiv kapacitet (markör = occupancysmål). Efficiency = realiserat FTE-bidrag / planerat FTE-bidrag, där planerat väger in Sen Factor (Senior 1,0 · Junior/Temp 0,7) — referens 100 %. Uppmätt per-ärende-tid saknas i Freshdesk-webhooken, så båda måtten bygger på modeled time (volym × AHT). Kapacitet/FTE = 7,5h × arbetsdagar (Mån–Fre minus helgdagar) × (1−25 % shrinkage); innevarande månad pro-rata. Ej officiellt prestationsmått — bemanningsanalys.
