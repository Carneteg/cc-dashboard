P4 · Historisk FTE-supply per pool (cc_pool_supply_history)

Skapar tabell för att spara faktisk FTE-bemannig per manad. Seed:ar med aktuella värden och möjliggör historisk gap-analys.
⏳ Kräver SQL-körning
-- Skapa historiktabell CREATE TABLE IF NOT EXISTS cc_pool_supply_history ( id BIGSERIAL PRIMARY KEY, pool_slug TEXT NOT NULL, year_month TEXT NOT NULL, -- Format: 'YYYY-MM' fte_supply NUMERIC(6,2) NOT NULL, note TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE(pool_slug, year_month) ); -- Seeda med aktuella varden fran cc_pools (kör en gång) -- Obs: Ändra datumintervallet efter era historiska data INSERT INTO cc_pool_supply_history (pool_slug, year_month, fte_supply, note) SELECT slug AS pool_slug, TO_CHAR(gs, 'YYYY-MM') AS year_month, fte_capacity AS fte_supply, 'Seeded from current cc_pools value' AS note FROM cc_pools CROSS JOIN generate_series( DATE_TRUNC('month', NOW() - INTERVAL '18 months'), DATE_TRUNC('month', NOW()), INTERVAL '1 month' ) gs ON CONFLICT (pool_slug, year_month) DO NOTHING; -- Verifiera SELECT pool_slug, COUNT(*) AS months, MIN(year_month), MAX(year_month) FROM cc_pool_supply_history GROUP BY pool_slug ORDER BY pool_slug;

P5 · Svenska arbetsdagar (ersätter hardkodad 9450)

FTE-beräkning baseras nu pa faktiska svenska arbetsdagar exklusive helger och röda dagar. Denominatorn 9450 (22,5 dagar × 7 h × 60 min) ersätts med kalenderbaserad beräkning. Implementeras i Edge Function computeFTE().
ℹ Logik i frontend + Edge Function
-- Svenska allmänna helgdagar beräknas dynamiskt i JS/Edge Function. -- Formel: FTE = (tickets × AHT_min) / (arbetsdagar_i_manaden × 7 × 60) -- -- Arbetsdagar = alla vardagar i manaden MINUS svenska helgdagar -- Svenska fasta helgdagar (exkl. rörliga): -- Nyarsdagen: 1 jan -- Trettondedag: 6 jan -- Forsta maj: 1 maj -- Nationaldagen: 6 jun -- Julafton*: 24 dec (*halvdag / vanligen ledig) -- Juldagen: 25 dec -- Annandag jul: 26 dec -- Nyarsafton*: 31 dec -- -- Rörliga helgdagar (baseras pa pasken): -- Langfredagen, Paskdagen, Annandag pask, -- Kristi himmelsfard, Pingst, Midsommarafton/dagen -- -- I frontend: se funktion swedishWorkingDays(year, month) nedan -- I Edge Function: implementera motsvarande logik i computeFTE()

P7 · Freshcaller API-nyckel

Berikarens v5-implementation stöder Freshcaller men kräver korrekt fristående Freshcaller API-nyckel (inte Freshdesk-nyckeln). Uppdatera Supabase Vault-hemligheten.
⏳ Kräver API-nyckel från plattformsägare
-- Uppdatera Freshcaller-hemlighet i Supabase Vault -- 1. Gå till Supabase Dashboard → Settings → Vault -- 2. Hitta hemligheten: FRESHCALLER_API_KEY -- 3. Ersätt med den fristående Freshcaller API-nyckeln -- (Hämtas under: Freshcaller → Admin → API) -- 4. Ingen kodandring krävs - enricher v5 hämtar automatiskt nyckeln -- Alternativt via SQL: SELECT vault.update_secret('FRESHCALLER_API_KEY', 'din-freshcaller-nyckel-här'); -- Verifiera att hemligheten finns: SELECT name, created_at, updated_at FROM vault.secrets WHERE name = 'FRESHCALLER_API_KEY';
